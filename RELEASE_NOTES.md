DuoMount v0.1.1-beta.1 combines the ShadowMountPlus host with the embedded Kraken Mount PS5 FPKG runtime.

- One ELF with the web interface, scanner, folder/image workflows and supported direct PS5 debug FPKG mounting.
- DuoMount startup notifications, its own icon and the detected game count after the library scan.
- Updated runtime branding across 31 languages; original credits and licenses retained.
- English and German documentation and a Payload Manager icon catalog.

Requires a compatible OnionHEN/kstuff-lite environment. Stop standalone ShadowMountPlus and Kraken Mount before loading DuoMount. Existing configuration, source and cache paths are retained. Use the unauthenticated management interface only on a trusted LAN.
